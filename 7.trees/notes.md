- Root : the top node in a tree
- Child : a node directly connected to another node when moving away from the root
- Parent : the converse notion of a child
- Sibling : a node with the same parent
- Leaf : a node with no children

## Examples

- Tree : a data structure in which each node has zero or more children
- Binary Tree : a tree in which each node has at most two children
- Binary Search Tree : a binary tree in which all the children on the left are less than the parent and all the children on the right are greater than the parent

## UseCases

- Directories : a tree structure is used to represent the file system
- HTML : a tree structure is used to represent the DOM
- JSON : a tree structure is used to represent the data
